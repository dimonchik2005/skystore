# SkyStore

Учебный проект интернет-магазина на Django.

Проект будет постепенно дорабатываться в процессе обучения и в дальнейшем может быть добавлен в портфолио.

## Реализовано

- создан Django-проект;
- создано приложение `catalog`;
- реализована главная страница;
- реализована страница контактов;
- настроена маршрутизация через `include`;
- HTML-шаблоны оформлены с помощью Bootstrap;
- реализована форма обратной связи;
- после отправки формы отображается сообщение об успешной отправке.
- динамический вывод товаров из PostgreSQL;
- страница с подробной информацией о товаре;
- переходы между каталогом и страницами товаров;
- базовый шаблон с общими элементами сайта;
- переиспользуемый подшаблон главного меню;
- форма добавления нового товара;
- проверка данных формы;
- загрузка изображений товаров;
- постраничный вывод каталога;
- контроллеры приложения catalog переведены на CBV;
- создано приложение blog;
- реализован полный CRUD блоговых записей;
- добавлена фильтрация опубликованных статей;
- реализован счётчик просмотров;
- шаблоны блога используют базовый шаблон и общее меню;
- модели блога зарегистрированы в административной панели;
- реализован полный CRUD продуктов;
- добавлена форма создания и редактирования продуктов;
- реализована проверка запрещённых слов;
- проверка выполняется без учёта регистра;
- добавлена проверка неотрицательной цены;
- формы оформлены с помощью Bootstrap;
- добавлена проверка формата и размера изображений.
